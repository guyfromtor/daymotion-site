Moods Help

Describe how a stop felt.

Moods turn a stop from a location into a memory. Use them to mark the feeling, tone, or energy of a place in a way that is easy to scan later.

Use moods Common questions

What Moods Do

Moods add emotional context to stops.

Stop context

Attach a mood to a stop so the place has more meaning than time and coordinates.

Presets

Use built-in moods for common feelings without creating a custom list first.

Custom moods

Create moods that match your own language, routines, and travel style.

Insights

Mood choices help DayMotion summarize the emotional pattern of a journey.

Create And Apply

You can manage moods in Settings or create one from a stop.

From Settings

Open My Moods to create custom moods, tune presets, and keep the mood list useful before you need it.

From a stop

When editing a stop, create a new mood if none of the existing choices fit what happened there.

On the journey

Apply moods while reviewing stops, then use Journal to add the story behind the feeling.

Later edits

You can revisit a stop and change the mood after the journey if the first label was not quite right.

Tips

Keep moods useful and easy to choose.

Use plain words

Short names like Calm, Busy, Fun, Tired, or Focused are easier to apply quickly.

Avoid duplicates

If two moods mean nearly the same thing, keep the one you would actually choose during review.

Match your routine

Create moods for patterns you care about, such as Work, Family, Errands, Travel, or Recovery.

Pair with notes

Use the mood for the headline feeling and the journal note for the details.

Questions

Common questions

Do I have to set a mood on every stop?

No. Add moods where they help the journey make sense later.

Can I create a mood while editing a stop?

Yes. If the existing choices do not fit, create a new mood from the stop and apply it there.

What is the difference between a mood and a journal note?

A mood is a quick label for how the stop felt. A journal note explains what happened or why it mattered.

Will mood changes update insights?

Yes. Insights use the moods saved on stops, so refining stop moods can change the journey summary.

Moods can reveal personal routines and feelings. Review them before sharing a journey memory or export.

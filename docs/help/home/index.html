Home Help

Start, resume, or review the day.

Home is the first place to start recording, return to a Journey already in progress, and open recent DayMotion memories. When an unfinished Journey can continue, DayMotion lets you add a connected new part or begin a separate Journey.

Starting from Home

Choose where the next recording belongs.

DayMotion shows these choices only when it finds an active or paused Journey that can continue. Otherwise, Start Journey begins a separate Journey immediately.

Start New Part

Choose this when the same overall Journey continues, such as a new day or chapter. The new recording stays connected to the unfinished Journey.

Start Separate Journey

Choose this for an unrelated outing. DayMotion ends the unfinished Journey and begins a separate Journey with its own Library entry.

No active journey

Journey in progress

Tips

Make Home part of your journey routine.

Start early

Start before the first meaningful movement so the journey begins with useful route context.

Check the state

If Home shows an active or paused Journey, add a new part when that Journey continues, or start separately when the next outing is unrelated.

Review after recording

Use previous journeys to refine stop names, notes, moods, and photos once the day is over.

Questions

Common questions

Should I start from Home or Map?

Use either entry point when available. Home is the simpler starting point; Map is better when you want to immediately watch route and stop capture.

What happens if a journey is already active?

When you start, DayMotion asks whether to use Start New Part or Start Separate Journey. A new part stays connected; a separate Journey ends the unfinished one and gets its own Library entry.

Can I edit a journey from Home?

Home gets you back to the journey. Edit stop details, moods, notes, photos, and journal text from the journey screens.

Home may surface recent journey activity. Review a journey before sharing details from it.

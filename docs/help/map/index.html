Read The Map

Use the route as the visual memory of the day.

DayMotion turns movement into a map-based record. The route, stop markers, timing, and distance work together so you can quickly understand what happened.

1Follow the route line

The route line shows the captured path across the journey. Curves and intermediate points help preserve the actual shape of travel.

2Read numbered stops

Stops are ordered from first to last. Tap a stop or open the Stops tab to review time, weather, mood, journal text, and photos.

3Check the journey state

Use the status controls to see whether DayMotion is recording, paused, or reviewing a completed journey.

4Move between journey views

The bottom tabs keep the Map close to the rest of the journey: Stops, Journeys, Settings, and other related detail screens.

Tips

When the map does not look right.

Give DayMotion precise location access

  • Precise location helps DayMotion record trustworthy routes, stops, and distance.
  • If the route looks sparse, check iOS location permissions and Low Power Mode.
  • If you pause a journey, DayMotion keeps the journey available but stops recording new movement.

Review instead of editing from the map

Use the Stops, Journal, Photos, and Insights views when you want to refine the memory attached to a place.

Questions

Common Map questions

Why does the route bend?

The route uses captured geometry so the journey reads like a path you traveled, not just direct stop-to-stop connectors.

Can I pause tracking?

Yes. Pausing keeps the journey available while DayMotion stops recording new movement.

What if a stop is wrong?

Open Stops or the journey detail screen to review captured stop information, notes, moods, and photos.

Map help may describe precise location and route tracking. Only share journey exports with people or services you trust.

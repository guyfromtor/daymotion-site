What Places Do

Overrides make repeated stops easier to recognize.

Preferred names

Use names that make sense to you, such as Home, Office, Gym, Favorite Cafe, or North Lot.

Recurring locations

When DayMotion sees the same place again, the remembered name can make the stop easier to scan.

Cleaner journeys

Custom names help Map, Stops, Journal, Photos, and exports read more naturally.

Editable list

Use Place name overrides in Settings to review and manage remembered names.

How Overrides Are Created

Rename a stop to create a remembered place name.

Place name overrides start from stop editing. When you change a stop name to something you prefer, DayMotion can remember that name for the place so future journeys use language that feels familiar.

Edit the stop

Open a captured stop and change its name from the default place label to the name you want.

Remember the place

The custom stop name becomes a place name override that can be reused when the same location appears again.

Manage in Settings

Open Place name overrides to review remembered names, clean up old labels, or remove names you no longer want.

Use precise names

Choose a name that will still make sense later, especially for places with many nearby stops.

Tips

Name places for memory, not just accuracy.

Use personal labels

Choose the name you would naturally say when telling the story of the day.

Avoid vague names

Names like Store or Parking can become confusing if you visit several similar places.

Fix from the stop

If a place looks wrong in a journey, rename the stop there first so the memory stays connected to the visit.

Review occasionally

Use Settings to remove stale overrides when a routine changes or a label no longer helps.

Questions

Common questions

How do I create a place name override?

Rename a stop. Changing the stop name is how DayMotion learns the preferred name for that place.

Why use Settings for places?

Settings gives you one place to review remembered names after they have been created from stops.

Will a custom name change old journeys?

The remembered name helps future recognition and review. Check the stop you edited when you need to confirm exactly where the name appears.

What if two places are close together?

Use more specific names and review the stop location. Nearby places can be easier to confuse when GPS signal is noisy.

Place names can reveal home, work, routines, or sensitive locations. Review names before sharing a journey memory or export.

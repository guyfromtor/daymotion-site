What You Can Do Here

Home keeps the main journey actions close.

Start

Begin a new journey when you want DayMotion to record movement, stops, weather, photos, moods, and notes.

Resume

Return to an active or paused journey without searching through previous records.

Review

Open previous journeys when you want to look back at a saved day.

Navigate

Move into Map, Stops, Journeys, and Settings from the main tab bar.

Use Home

Pick the action that matches the journey state.

No active journey

Start a journey before moving if you want the route and stops to read as one continuous memory.

Journey in progress

Use Home to jump back to the active journey, then check Map or Stops to see what DayMotion has captured.

Paused journey

Resume before relying on new stop detection. A paused journey keeps its earlier stops, notes, and photos.

Past journey

Open previous journeys when you want to review the map, stops, photos, journal, and insights later.

Tips

Make Home part of your journey routine.

Start early

Start before the first meaningful movement so the journey begins with useful route context.

Check the state

If Home shows an active or paused journey, open it before starting a new one.

Review after recording

Use previous journeys to refine stop names, notes, moods, and photos once the day is over.

Questions

Common questions

Should I start from Home or Map?

Use either entry point when available. Home is the simpler starting point; Map is better when you want to immediately watch route and stop capture.

What happens if a journey is already active?

Home keeps the active journey visible so you can return to it instead of accidentally starting another recording.

Can I edit a journey from Home?

Home gets you back to the journey. Edit stop details, moods, notes, photos, and journal text from the journey screens.

Home may surface recent journey activity. Review a journey before sharing details from it.

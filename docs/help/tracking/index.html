Settings

Tune how DayMotion tracks movement.

Tracking settings control automatic stop detection, activity event rows, battery behavior, display units, and stop thresholds.

Core Controls

  • Auto-detect stops lets DayMotion pause stop capture when you appear stationary.
  • Show activity events keeps started, paused, resumed, and stopped rows visible in the journey timeline.
  • Battery saver mode reduces GPS polling frequency when preserving battery matters more than route detail.

Units And Thresholds

Display units change journey and weather measurements. Stop radius and stop duration control how close and how long movement needs to settle before DayMotion treats a place as a stop.

Choosing Values

Use smaller radius and shorter duration values when you want more precise stops. Use larger values when you prefer fewer, more intentional stops and less noise from brief pauses.

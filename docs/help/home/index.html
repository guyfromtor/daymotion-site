Home

Start, resume, or review the day.

The Home screen is the first place to begin a journey, return to an active one, or open recent DayMotion memories.

What You Can Do Here

  • Start a new journey when you are ready to record movement, stops, weather, photos, moods, and notes.
  • Resume an active or paused journey without digging through Settings or previous records.
  • Open previous journeys when you want to review a saved day.
  • Move into the Map, Stops, Journeys, and Settings tabs from the main navigation.

Active Journeys

When a journey is already running, Home keeps the active journey close. Use it to jump back in, continue recording, or review the current state before switching to another screen.

Tips

Start a journey before you begin moving if you want the route and stops to read as one continuous memory. If a journey is paused, resume it from Home before relying on new stop detection.
